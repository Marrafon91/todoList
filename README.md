# 📝 TodoList — Gerenciador de Tarefas

Aplicação Full Stack para gerenciamento de tarefas, desenvolvida com **Java + Spring Boot** no backend e **React + TypeScript** no frontend.

O projeto foi desenvolvido com o objetivo de praticar e consolidar conceitos de desenvolvimento Full Stack, principalmente **API REST, Spring Data JPA, PostgreSQL/H2, React, TypeScript, consumo de APIs com Axios, componentização, gerenciamento de estado, filtros, CRUD e responsividade**.

---

## 📸 Sobre o projeto

O TodoList permite que o usuário organize suas tarefas em um único lugar.

É possível:

- Criar tarefas
- Editar tarefas
- Excluir tarefas
- Excluir todas as tarefas
- Marcar tarefas como concluídas
- Pesquisar tarefas
- Filtrar tarefas por situação
- Filtrar por prioridade
- Filtrar por categoria
- Visualizar estatísticas do painel
- Organizar tarefas por categorias
- Definir prioridade
- Definir data de vencimento
- Utilizar a aplicação em dispositivos menores

O projeto também possui uma interface responsiva para desktop, tablet e celular.
